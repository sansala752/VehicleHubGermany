VehicleHubGermany

A modern full-stack Vehicle Inventory Management System built for managing vehicles, tracking availability, and organizing dealership data efficiently.

📌 Features
-> Add, edit, and delete vehicles
-> Track vehicle status (Available, Sold, Reserved)
-> Upload and manage vehicle images
-> View detailed vehicle information
-> Inventory dashboard with statistics
-> Fast and responsive UI
-> REST API backend integration


🛠️ Tech Stack
Frontend
React + TypeScript
Tailwind CSS
Vite
React Router
Backend
Node.js
Express.js
TypeScript
Prisma 
PostgreSQL (Supabase)

📂 Project Structure

🚀 Getting Started

1. Clone the repository
git clone https://github.com/sansala752/VehicleHubGermany.git

2. Install dependencies
Frontend
    cd client
    npm install
    npm run dev

Backend
    cd server
    npm install
    npm run dev


⚙️ Environment Variables

* Create a .env file in the server folder:

PORT=5000
DATABASE_URL=your_database_url
